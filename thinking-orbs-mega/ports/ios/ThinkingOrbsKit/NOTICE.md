# Attribution

ThinkingOrbs is an independent native Swift implementation derived from
[thinking-orbs](https://github.com/Jakubantalik/thinking-orbs) by Jakub Antalik.

The upstream project provides the visual concepts, activity states, geometry,
animation formulas, density profiles, tuned 20-point and 64-point presets,
accessibility behavior, and original TypeScript implementation. The upstream
copyright and MIT license are preserved in `LICENSE`.
