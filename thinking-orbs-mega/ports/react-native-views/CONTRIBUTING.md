# Contributing

Thanks for helping improve `react-native-thinking-orbs`.

## Development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make the smallest change that solves the problem.
4. Add or update tests when behavior changes.
5. Run `npm run check`.
6. Open a pull request with a clear description and screenshots or recordings
   for visual changes.

## Guidelines

- Preserve the six public state names unless a major release is planned.
- Keep the runtime free of additional dependencies when possible.
- Test both the 20-pixel and 64-pixel design profiles.
- Keep accessibility and reduced-motion behavior intact.
- Preserve the upstream attribution in `LICENSE` and `NOTICE`.

By contributing, you agree that your contribution is licensed under the
repository's MIT License.
