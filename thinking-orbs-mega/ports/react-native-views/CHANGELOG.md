# Changelog

All notable changes to this project will be documented here.

## 0.1.0

- Added a React Native renderer for iOS and Android.
- Added all six original thinking-orb states.
- Added arbitrary sizing, theme selection, speed, frame rate, and density.
- Added app lifecycle and reduced-motion handling.
- Added deterministic frame generation for custom renderers and tests.
- Added TypeScript types, package exports, CI, and release documentation.
